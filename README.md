# 🇬🇧 English

## About the Project

Beit Hanoun Memory is a digital memorial archive dedicated to documenting and preserving the memory of the martyrs of Beit Hanoun from October 7, 2023, onward.

The project provides a digital space for preserving names, stories, photographs, and personal memories, making them accessible to current and future generations.

It uses technology as a means of documentation, remembrance, and preserving collective memory.

## 🎯 Project Goals

- Document the martyrs of Beit Hanoun.
- Preserve personal stories and photographs.
- Create an accessible digital memorial archive.
- Encourage community participation in documentation.
- Preserve collective memory for future generations.

## ✨ Key Features

- Digital archive of martyrs.
- Search and browse documented records.
- Photo documentation.
- Arabic and English language support.
- RTL and LTR interface support.
- Light and dark display modes.
- Community submissions for information and photographs.
- Administrative review and approval system.

# 🇵🇸 العربية

## عن المشروع

**ذاكرة بيت حانون** هو أرشيف رقمي توثيقي يهدف إلى حفظ ذاكرة شهداء مدينة بيت حانون، منذ السابع من أكتوبر 2023 وحتى اليوم.

يوفر المشروع مساحة رقمية لتوثيق الأسماء والقصص والصور والذكريات الشخصية، وإتاحتها للأجيال الحالية والقادمة.

ينطلق المشروع من توظيف التكنولوجيا كوسيلة للتوثيق وحفظ الذاكرة الجماعية، وضمان بقاء الحكايات حاضرة.

## 🎯 أهداف المشروع

- توثيق شهداء مدينة بيت حانون.
- حفظ القصص الشخصية والصور والذكريات.
- إنشاء أرشيف رقمي يسهل الوصول إليه.
- إتاحة المشاركة المجتمعية في عمليات التوثيق.
- الحفاظ على الذاكرة الجماعية للأجيال القادمة.

## ✨ أبرز المميزات

- أرشيف رقمي للشهداء.
- إمكانية البحث واستعراض السجلات الموثقة.
- توثيق الصور.
- دعم اللغتين العربية والإنجليزية.
- دعم اتجاهي العرض RTL وLTR.
- الوضع الليلي والنهاري.
- استقبال مساهمات المجتمع لإضافة المعلومات والصور.
- نظام لمراجعة المساهمات واعتمادها إدارياً.

## 🛠️ التقنيات المستخدمة

يعتمد المشروع على تقنيات ويب حديثة وخدمات سحابية لبناء المنصة وإدارتها.
